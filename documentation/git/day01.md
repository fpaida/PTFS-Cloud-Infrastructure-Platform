# Git Day 1 – AWS DevOps Course

**Date:** August 2, 2026

## Objective

Learn the Git fundamentals while working from an Amazon EC2 Linux server using VS Code Remote SSH.

---

## Environment

- AWS EC2
- Amazon Linux 2023
- VS Code Remote SSH
- GitHub
- Git 2.50.1

---

## Skills Learned

- Configure Git
- Configure GitHub SSH authentication
- Clone repositories
- Initialize repositories
- Track file changes
- Stage changes
- Commit changes
- Push changes to GitHub
- View repository history
- Compare file changes

---

## Commands Practiced

```bash
git init
git clone
git status
git add
git commit
git push
git log
git diff
git show
```

---

## What I Learned

Today I successfully connected my Amazon EC2 instance to GitHub using SSH authentication. I also connected VS Code directly to the EC2 instance using Remote SSH, allowing me to edit files and manage Git repositories from my cloud server.

---

## Outcome

- EC2 connected to GitHub
- SSH authentication configured
- Git repositories created
- Commits successfully pushed
- VS Code connected to EC2
